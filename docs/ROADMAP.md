# Planned: Guides in 2.5.0

Guides are planned for version 2.5.0, not part of the current release.

- Game-specific guides with a rich-text editor, headings, images, and links.
- Attach catalog items as linked cards that stay connected to the correct game and item ID.
- Link one or more guides to a build or a specific build variant without copying the guide text.
- Save drafts privately, then share a guide when its author chooses.
- Sanitize shared content and keep revision history so authors can correct mistakes.

Before implementation, settle image storage, sharing permissions, and how guide revisions should appear to readers of a linked build.
