BancyCraft 0.4.0 expands gearsets and brings the Dragonwilds production ledger into the desktop app.

- 139 gearset bundles: 37 Dragonwilds, 20 Valheim, and 82 Enshrouded, including 23 cosmetic sets. Dragonwilds bundles support seven alternative helmets. Each bundle adds its actual pieces to a shopping list.
- Dragonwilds-only Production Ledger with the website's merchant catalog, order calculator, profit modes, production timing, hotbar, and recovery guide, available offline.
- Settings accepts signed BancyCraft access keys. Bancy.gg navigation stays hidden until a valid key is supplied; locking removes the key and closes the community window.
- Unlocked Dragonwilds users can open the existing website's shared bank inside the app. Website sign-in and member/admin permissions still apply. Merchant orders can prefill a request for review; nothing is submitted automatically.
- Existing website ledger remains available. Local plans, shopping lists and supplies remain independent of community access.

If you already have 0.3.0, use Settings to check for updates, download, and restart to install. For 0.2.0 or earlier, install this version once; future updates are available in Settings. Windows x64; the installer has no purchased Windows publisher certificate, and in-app updates verify the bundled release-signing key.

Gearsets reflect the current imported catalogs. Missing recipes and acquisition information remain explicit. Access keys reveal the community interface; they do not grant website membership or administrative privileges.
