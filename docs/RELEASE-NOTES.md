BancyCraft now turns game-scoped item searches into saved shopping lists and temporary quick lists.

- Item images, Type / Item type filters, station filtering, quantity inputs and numbered results.
- Select multiple items, choose an existing list or create a new list in the side drawer, and open it from the notification.
- Collapsible Vendors, Gathering, Other sources, Pre-crafts and Target items with exact recipe quantities, partial progress, section controls and resets.
- Completed crafts satisfy their ingredient branches while preserving materials still needed by other crafts. Recipe alternatives and direct acquisition are selectable.
- Saved lists keep their progress. Quick lists automatically remove themselves when all their targets are complete.
- Starter armor bundles for Dragonwilds, Valheim and Enshrouded.
- Settings now checks GitHub Releases, downloads newer versions, verifies the release signature and restarts to install them.
- Existing plans and supplies migrate with an original workspace backup.

Install this version once if upgrading from 0.2.0 or earlier; those builds do not contain the connected updater. Future versions can update inside Settings. Local crafting works offline without Bancy.gg or Blackbox.

Recipe and acquisition coverage depends on the imported sources. Unknown recipes and sources remain marked; gathering counts are not converted to creature or harvest counts. Windows x64; the initial installer does not have a purchased Windows publisher certificate.
